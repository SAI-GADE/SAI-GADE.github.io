# Manjusha — Mechanical Engineering Portfolio

This is a static HTML/CSS portfolio designed for GitHub Pages.

## Files
- `index.html` — homepage
- `projects/` — individual project pages
- `assets/style.css` — styling
- `assets/Manjusha_CV.pdf` — CV copied from the uploaded file

## Before publishing
1. Replace `YOUR_EMAIL_HERE`, `YOUR_LINKEDIN_URL`, and `YOUR_GITHUB_URL` in `index.html`.
2. Replace the white image placeholders with your project images.
3. Add any certifications you want to show.
4. Review all wording and dates.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new repository named `YOURUSERNAME.github.io`.
3. Upload all files in this folder to the repository root.
4. Open Settings → Pages.
5. Choose deployment from the `main` branch and `/ (root)`.
6. Your website will be available at `https://YOURUSERNAME.github.io/`.

## SEO
The homepage already includes a title, description, author metadata and the full name from the CV. Keep the same professional name across the website, GitHub and LinkedIn.
